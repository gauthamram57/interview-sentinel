# Dashboard

Web-based interviewer dashboard for **Interview Sentinel**.

The dashboard provides interviewers with a live view of an interview session by displaying events received from the Interview Sentinel backend in real time.

It is intended to improve interview transparency by presenting observable environment verification signals without making automated hiring decisions.

---

## Features

- Live interview session monitoring
- Real-time event updates
- Session status visualization
- WebSocket communication
- Candidate connection status
- Security event timeline
- Lightweight client-side application

## Running

Open the dashboard directly

```bash
index.html
```

or serve it using a simple web server.

Example:

```bash
python3 -m http.server 8080
```

Then visit

```
http://localhost:8080
```
